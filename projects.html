Projet 1 · PHP / API

MovieDB

Application web consacrée aux films, séries et acteurs. Elle interroge l’API TMDB pour afficher les contenus populaires, les mieux notés, les sorties à venir et permettre des recherches par titre, genre, région ou acteur.

TechnologiesPHP 8+, HTML, CSS, API TMDB, cURL
Environnement LinuxUbuntu / Debian, PHP et php-curl
ServeurApache ou serveur PHP intégré

Fonctionnalités réalisées

  • Connexion à une API externe
  • Pages de recherche et de découverte
  • Affichage dynamique des résultats
